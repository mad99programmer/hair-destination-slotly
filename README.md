# Slotly Admin Android APK

Simple WebView wrapper for the existing Slotly Admin panel.

Start URL: https://slotly-usly.onrender.com/admin/login.html

No push notifications or Firebase are included.

## Build without Android Studio
1. Put this project in a GitHub repository.
2. Open Actions -> Build Slotly Admin APK.
3. Run the workflow.
4. Download the `slotly-admin-debug-apk` artifact.
